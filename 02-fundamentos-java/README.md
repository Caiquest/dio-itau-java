# ☕ Módulo 2 — Fundamentos para começar a programar em Java

Aulas práticas e exercícios do segundo módulo do bootcamp. Cada pasta é um projeto independente do IntelliJ, com o código em `src/`.

## 📘 Aulas

| # | Projeto | O que pratiquei |
|:-:|---------|-----------------|
| 01 | [Primeiro programa](01-primeiro-programa-dio/src/Program.java) | `Hello World` e argumentos de linha de comando (`args[]`) |
| 02 | [Padrões de desenvolvimento](02-padroes-de-desenvolvimento/src/Program.java) | `Scanner`, constantes (`static final`) e inferência de tipo com `var` |
| 03 | [Tipos primitivos e keywords](03-tipos-primitivos-keywords/src/Program.java) | `boolean`, `byte`, `int`, `long`, `float`, `char` e `String` |
| 04 | [Operadores lógicos e de atribuição](04-operadores-logicos-atribuicao/src/Program.java) | `&&`, `\|\|` e comparações — “posso dirigir?” |
| 05 | [Operadores aritméticos](05-operadores-aritmeticos/src/Program.java) | Operações básicas, `Math.sqrt`, `Math.pow`, incremento e decremento |
| 06 | [Operadores bitwise](06-operadores-bitwise/src/Program.java) | `&`, `\|`, `^`, `~`, `<<`, `>>` e `Integer.toBinaryString` |
| 07 | [Estruturas condicionais](07-estruturas-condicionais/src/Program.java) | `if` / `else if` / `else` e operador ternário |
| 08 | [Switch case](08-estrutura-switch-case/src/Program.java) | `switch` clássico × *switch expression* com `->` e `yield` |
| 09 | [Laço `for`](09-estrutura-de-repeticao/src/Program.java) | `for` com `continue` — números pares de 0 a 100 |
| 10 | [Laços `while` e `do-while`](10-estrutura-de-repeticao-while/src/Main.java) | Percorrendo os argumentos do programa com `while` e `do-while` |

## 🧩 Exercícios

| Exercício | Desafio | Conceitos |
|-----------|---------|-----------|
| [fundamentos-ex01](fundamentos-ex01/src/Program.java) | Recebe nome e data de nascimento e informa a idade | `LocalDate`, `Period`, `DateTimeFormatter` |
| [fundamento-ex02](fundamento-ex02/src/Program.java) | Calcula a área de um quadrado | `Scanner`, `double`, `printf` |
| [fundamento-ex03](fundamento-ex03/src/Program.java) | Calcula a área de um retângulo | `Scanner`, operadores aritméticos |
| [fundamento-ex04](fundamento-ex04/src/Program.java) | Diferença de idade entre duas pessoas | `Math.abs` (resolvido sem usar `if`) |
| [estruturas-controle-ex01](estruturas-controle-ex01/src/Main.java) | Tabuada de 1 a 10 de um número | `for` |
| [estruturas-controle-ex02](estruturas-controle-ex02/src/Main.java) | Calculadora de IMC com classificação do resultado | `if` / `else if` encadeado |
| [estruturas-controle-ex03](estruturas-controle-ex03/src/Main.java) | Pares ou ímpares de um intervalo, em ordem decrescente | `while` para validar a entrada, `for` decrescente |
| [estruturas-controle-ex04](estruturas-controle-ex04/src/Main.java) | Lê números até encontrar um que não seja divisível pelo inicial | `while (true)`, `continue` e `break` |
